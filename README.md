# Nour Academy — Espace enseignant

Une petite application pour gérer une classe : rechercher des élèves, suivre leurs absences et leurs notes, et ajouter de nouveaux élèves.

## Lancer le projet

```bash
npm install
npm run dev
```

Pour créer la version de production : `npm run build`.
